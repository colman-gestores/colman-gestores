Configuración inicial — una sola vez.
Necesitamos conectar tu base de datos Firebase.

🔧 Pasos para configurar

1
Entrá a console.firebase.google.com con tu cuenta Google y creá un proyecto nuevo (ej: colman-gestores).
2
Realtime Database → Crear base de datos. Elegí southamerica-east1 y modo bloqueado.
3
En Reglas de la base de datos, pegá:
{"rules":{".read":"auth != null",".write":"auth != null"}}
4
Authentication → Comenzar → Correo/Contraseña. Creá un usuario por gestor.
5
Copiá la URL de tu base de datos:
https://tu-proyecto-default-rtdb.firebaseio.com
6
Copiá también la API Key de tu proyecto (Configuración del proyecto → General → apiKey).
⚠️ Verificá los datos ingresados.
